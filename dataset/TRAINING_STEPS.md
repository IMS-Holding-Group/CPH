# خطوات تدريب نموذج الذكاء الاصطناعي

## المتطلبات

```bash
pip install scikit-learn
```

## الداتاسيت

الملف `training_data.json` يحتوي على عينات لتدريب النموذج:
- **text**: وصف البلاغ (نص عربي)
- **report_type**: نوع البلاغ (ابتزاز / احتيال)
- **threat_level**: مستوى التهديد (عالي / متوسط / منخفض)

## خطوات التدريب

### 1. التحقق من الداتاسيت

```bash
cd D:\VSCode\Projects\CPH
python -c "import json; d=json.load(open('dataset/training_data.json')); print(f'عدد العينات: {len(d[\"samples\"])}')"
```

### 2. تشغيل التدريب

```bash
python train_model.py
```

سيظهر:
- دقة تصنيف نوع البلاغ (ابتزاز/احتيال)
- دقة تصنيف مستوى التهديد
- تقرير التصنيف لكل فئة

### 3. الناتج

يُحفظ النموذج في:
```
D:\VSCode\Projects\CPH\models\cph_model.pkl
```

### 4. استخدام النموذج

بعد التدريب، شغّل التطبيق:
```bash
python app.py
```

النموذج يُحمّل تلقائياً ويُستخدم في صفحة التحليل عند فتح أي بلاغ.

## إضافة بيانات جديدة

1. افتح `dataset/training_data.json`
2. أضف عينات جديدة في مصفوفة `samples`:
```json
{
  "text": "وصف البلاغ بالعربية",
  "report_type": "ابتزاز",
  "threat_level": "عالي"
}
```
3. أعد تشغيل التدريب: `python train_model.py`

## تحسين النموذج

- **زيادة العينات**: كلما زادت البيانات، تحسّنت الدقة
- **توازن الفئات**: تأكد من وجود عدد متقارب من عينات الابتزاز والاحتيال
- **تنوع الوصف**: استخدم أوصاف متنوعة (منصات مختلفة، مبالغ مختلفة)
