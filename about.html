المُخبر الرقمي الذكي

Cyber-Police Hub

نبذة عن المشروع

منصة أمنية متقدمة لتحليل بلاغات الابتزاز الإلكتروني (حسابات التواصل الاجتماعي) باستخدام الذكاء الاصطناعي لكشف التزييف، وتحليل بصمة الأسلوب، وربط الجرائم المتشابهة آلياً لمساعدة المحققين.

الفئة المستهدفة

الأجهزة الأمنية (مكافحة الجرائم المعلوماتية)، والمواطنين المتعرضين للابتزاز.

نطاق المنصة

منصة مخصصة لبلاغات الابتزاز الإلكتروني والاحتيال المالي فقط. الضحية يرفع صور المحادثات أو روابط المواقع المحتالة، والنظام يجري تحليلاً تلقائياً.

الوظائف الذكية

  • تحليل الروابط فوراً: عند إدخال رابط موقع الابتزاز، النظام يتبع المصدر ويعطي تقريراً: (السيرفر في أي دولة؟ هل مخفي خلف VPN؟ هل مسجل في القوائم السوداء؟)
  • كشف الديب فيك: تحليل الصور والفيديو بالذكاء الاصطناعي لتحديد نسبة التزييف (مثلاً: هذا الفيديو مفبرك بنسبة 90%).
  • تحليل هوية الحساب: تاريخ إنشاء الحساب، تغييرات اسم المستخدم، فحص المتابعين (بوتات أم حقيقيون).
  • تحليل أسلوب الكلام (Stylometry): ربط القضايا المتشابهة – إذا أسلوب الكتابة متطابق في بلاغات مختلفة، النظام يربطها ويقول: "المبتز غالباً هو نفس الشخص".
  • البحث العكسي عن الصور: البحث عن صورة البروفايل أو أي صورة عبر منصات التواصل لإظهار الهوية الحقيقية إن وُجدت.
  • التقرير الجنائي الآلي: تحميل تقرير PDF كامل لكل بلاغ للمحقق.

بنية الصفحات

  • صفحة الضحية: رفع صور المحادثات، إدخال يوزر المبتز، وصف البلاغ. تحت النموذج: حالة الطلب (قيد التحليل / تحت التحقيق / مغلق).
  • لوحة المحقق: قائمة البلاغات مع لمبة الخطر (أحمر = خطر مؤكد، أصفر = اشتباه). عرض شبيه بالشات: جديد، قديم، محلول أو لا.
  • صفحة التحليل: نموذج المحقق الكامل – تشغيل تحليل الرابط، الحساب، الصور، الأسلوبي، البحث العكسي، وزر تحميل التقرير PDF.
  • صفحة التواصل: شات بين الضحية والمحقق.
  • صفحة الإدارة: تعديل حالة البلاغ، إضافة ملاحظات، تعيين المحقق.
